# CC-Switch 原生桌面验收

2026-11-05，官方 Linux x86_64 **4.0.25**，在全新 Ubuntu 24.04 容器中运行真实 Tauri/WebKitGTK 桌面程序，用 Xvfb 显示、AT-SPI 和 X11 完成原生界面操作。未挂载用户 HOME、配置、Skills 或认证；只挂载公开包与合成证据。官方安装包 URL/SHA-256、容器镜像 digest、13 项检查、84 个源文件哈希及证据哈希见 [receipt.json](receipt.json)。

实际完成：单项 ZIP 安装、含分类嵌套目录的 13 项 ZIP 安装、两项选择包安装、Codex 关闭/重新启用、单项卸载保留其他技能、全量卸载、两项卸载。每阶段对主副本及真实 Codex/Claude 同步目标逐文件核对。默认同步为软链接，资源本身没有软链接。[原生 Codex 发现结果](06-codex-discovery.json) 来自同一隔离账户的实际同步入口，13 项全部启用且无错误；内置系统技能另列，未当作项目资产。

截图保存单项/两项安装、ZIP 文件选择、卸载及仓库配置状态；02-all-zip-chooser.png 是安装前的文件选择器，不是13项安装完成截图。13项终态由阶段 JSON、原生可访问性树和实际 Codex 发现共同证明。最小容器缺少中文字体，部分截图描述显示方框；可访问性文本和原文件中文保持完整。阶段 JSON 保存资源和目标路径，文本保存原生可访问性树。[操作日志](skill-operations.log) 仅保留测试账户的 Skill 操作，无凭据或用户配置。批量卸载是异步操作，证据取其终态，不能将瞬时剩余数量当作失败或成功。

实测边界：

- Add Skill → Install from ZIP 可导入本地包；Import from this computer 扫描已有应用 Skills，不是任意目录选择器。
- 重复 ZIP 导入跳过同名技能，不覆盖更新；Check Updates 对本地包返回最新不代表远程升级已验。
- Manage repositories 接受仓库根 URL 与 branch main；`tree/main/skills` URL 被拒绝。配置成功显示 0 项，与尚未发布的远端状态相符，不能算远程安装通过。
- 原生 macOS、用户自己安装的版本、发布仓库安装和更改远端版本后的升级均未验证。

测试包已通过界面卸载，主副本和同步入口中均无项目资产；CC-Switch 自动备份与 Codex 生成的内置技能只存在于测试账户。证据提取后已删除整个专用容器。未改动真实用户安装。

复验使用官方程序自身的上述菜单与完整普通 ZIP 包，不依赖项目安装器。桌面显示和可访问性工具仅为开发验收环境，不是产品运行依赖。
