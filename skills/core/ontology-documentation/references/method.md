# 建议文档骨架

1. 模型标识、版本、审查日期、适用范围、读者。
2. 业务目标与 competency questions；哪些数据不足以回答。
3. 术语表与概念层次，定义/同义词/角色边界。
4. 节点目录：名称、业务定义、标识范围、主键、属性、来源、生命周期。
5. 关系目录：两端、方向、语义、每端基数、多重边键、时效、来源。
6. 约束目录：标准定义、业务规则、执行位置、例外与验收方法。
7. 标准裁剪/业务扩展/图映射表，保留、近似和未映射语义及影响。
8. 来源与许可、业务/推理/实现验证证据、未决事项。
9. 变更历史、兼容性、迁移/回滚建议。

项目自主模板；字段为空应写未知或不适用。代码/JSON 示例用于表达模型，未经运行不能标为运行证据。
