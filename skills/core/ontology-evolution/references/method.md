| 变化 | 典型影响 | 必需证据 |
| --- | --- | --- |
| 增加可选属性 | 通常加法兼容 | 旧消费者允许额外字段 |
| 增加必填属性/收紧基数 | 旧数据可能不符合 | 空值分布、回填和例外策略 |
| 主键/身份范围变化 | 实体合并/拆分、边重连 | 碰撞与历史追溯清单 |
| 整数改字符串 | 序列化/比较/排序变化 | 消费者回归样例 |
| 关系反向 | 原有路径失效 | 方向映射和查询语义复核 |
| OWL 限制或上游定义改变 | 业务解释可能变化 | 精确标准版本、IRI 和差异依据 |

版本建议按影响而非文件数量决定。合并/删除信息通常不能用简单逆操作恢复，回滚需要保留旧快照和原标识映射。

这是项目自主演进方法，不提供任何数据库迁移语法。
