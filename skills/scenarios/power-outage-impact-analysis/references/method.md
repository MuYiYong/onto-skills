# 电力领域的最小方法

这是项目原创方法，不是 IEC 条款、CGMES 配置文件或调度规则。来源索引见 [sources.json](sources.json)，概念记录见 [domain.json](domain.json)。

身份：utility_id 限定设备/端子/连接点/回路/供电点/客户的编号范围。端子属于设备，端子与连接点的关联属于具体拓扑版本。禁止以同名、同回路或地理接近替代连接证据。

时间：统一 UTC；有效区间为 [valid_from, valid_to)，空终点只有在明确“持续有效”时使用。event_as_of 选择业务时点，knowledge_cutoff 限制当时已经收到的记录。观测迟到不能改变“当时已知什么”的回溯；冲突活跃版本/状态需列明并停止确定结论。

状态：closed/open/unknown 与 available/unavailable/unknown 明确编码。正常设计状态不是当前状态。缺失状态等同未确定，不等同 open 或 closed。已知闭合边产生确定拓扑连接；未知开关只产生可能连接。已知可用电源产生确定可达；未知 DER 只产生可能供电。先移除情景指定不可用设备，再分别求确定/可能可达。

范围：报告回路限制输出的供电点/客户，不应截断相关边界电源路径。保留供电点级结果，再按时效有效客户绑定去重。确定可达仅表示拓扑候选筛查未失去全部已知路径，不证明有电、容量充足、保护配合或允许反送电。

停复电：计划事件输出 projected impact，不能计实际停电。实际设备故障也不直接证明客户中断。实际中断/恢复以服务证据记录分段；同供电点区间求并集后累计时长，重复中断不能折叠成一个连续长段。未知恢复时刻保留 open，不用接收时间代替。

输出结论带证据链、状态不确定原因、源版本与检查边界。禁止生成操作性倒闸指令；超出聚合拓扑的相别、潮流、保护、容量与孤岛判断交有权人员和适当工具复核。
