# 多头借贷时序规则

这是原创业务建模建议，阈值需机构确认。最低输入：稳定借款人身份、独立机构映射、贷款身份、有效区间和余额/结清口径。申请/查询不能替代放款负债。

区间用 [valid_from, valid_to)，结束为空若表示尚未结束必须写清；未知结束与未结束不可混用。查询 as_of 时先检查 valid_from <= as_of 且 (valid_to 为空或 as_of < valid_to)，再按机构去重。晚到记录只影响其实际有效时间；observed_at 用于“当时已知什么”的回溯，不能代替事件时间。

滚动窗口区分“窗口内曾出现”和“同一时刻并存”。窗口内先后两笔不重叠贷款不应被重叠负债规则误报；重叠分析可找候选事件边界，按每段的有效机构集合计数。金额聚合固定时点/币种/余额口径，不将授信额度加放款额。

记录身份使用 source_system + record_id；重复导入不重复计数，不同真实事件即使同端点也不折叠。撤销/冲正追踪原记录。集团/分支统一粒度后才计“多机构”，保留映射来源与生效时间。

多主体关联：手机号可复用、账户可代收，共享值不是主体相等。关系必须有有效区间、来源和匹配置信度；只在时间重叠及任务范围内用于候选关联。风险候选不是欺诈事实或自动拒贷决定。
