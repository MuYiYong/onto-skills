# 有界工作示例

输入（虚构）：B1 的贷款 A 来自机构 L1，区间 [2026-01-01,2026-03-01)；贷款 B 来自 L2，区间 [2026-01-15,2026-02-15)。以 2026-02-01 为时点，示例规则“至少两家有效贷款机构”产生候选 B1，证据是 A/B 与 L1/L2。

反例：B2 同一家 L1 的两次放款只计一家；B3 的历史贷款已结清，另有 L2 征信查询，不产生当前多头候选。B1/B2 共享手机号只增加待核实关联，不合并身份。手机号先后被不同主体使用且区间不重叠，不形成同一时点共享关联。

输出：Borrower、Lender、Loan、Inquiry、Disbursement、Phone/Account；BORROWS、PROVIDES、USES_PHONE 等关系带身份/时效。贷款业务身份与事件来源键均独立；业务问题“当时知道什么”还需 observed_at 过滤。阈值与主体匹配仍需业务确认。
