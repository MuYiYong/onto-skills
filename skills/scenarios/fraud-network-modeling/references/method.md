# 欺诈网络证据方法

把事实、关联、指标、假设、结论分别表达：例如 Transaction 是观测事实，SHARES_DEVICE 是有证据的关联，短期高频转账是指标，SuspectedGroup 是待复核假设。结论需保留审核者角色、依据和时间，不能把模型推断回写成原始事实。

共享标识不是实体相等：公共 IP、家庭电话、公司收款账户、二手设备和代理交易都可能是正常反例。要复核匹配方法、有效期和高频公共节点，避免公共服务节点把整个网络粘在一起。

关系应保留业务方向、有效/观测时间和来源事件 ID，多份证据用 Observation/EvidenceRecord 或可区分的多重边表达。证据可撤销或冲正，更新时保留历史；多个来源不自动是独立证据。

风险链路先约束窗口与事件先后，再做关联。A→B→C 的资金路径若先后顺序反过来，不能作为同一连续流转链。设置业务意义上的边类型/跳数/时间界限以控制解释范围，而非宣称模型已优化查询性能。

候选子图包含参与主体、证据边、假设规则、反证和人工复核状态。群体标签不赋给所有邻居；共同所有权或交易对手也不等于欺诈共同体。
