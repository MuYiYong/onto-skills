# 工作示例

输入两个SBOM均含 SPDXRef-lib，A为1.0、B为2.0；仅A有受信人工映射和host-H安装证据。通告ADV1修订1受影响，修订2不受影响，但修订2的知识时间在历史截点之后。

交付保留A/B独立身份；选修订1，列host-H为受影响候选并引用https://vendor.example/security/ADV1@1。B未知；依赖util没有安装证据。CVSS10.0和补丁发布不证明被利用或安装修复。将截点移至11月9日可选修订2，仍只改变精确映射产品的断言。

反例：错误版本/其他通告的产品映射、同修订冲突、缺少影响/行动说明都不得判为安全；草稿不替代示例政策下的正式修订。标准支持产品状态和身份边界，图结构、人工映射与判定截点为项目整理。此例不输出生产修复指令。
