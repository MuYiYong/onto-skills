# 从“同产线同批”到物料身份与事件

输入：“两个批次共用搅拌机，前一批有不合格检验，后一批是否都召回？”

先要求 source_system/site_id/lot_id、实际投入产出事件和检验证据。物料定义不是批次，设备也不是血缘。若 A 的50kg 经返工 E3 形成 B的48kg 和报废2kg，A→E3→B 是可追溯路径；另一个仅共用机器的 C 没有路径。

输出候选 B及明确事件路径，记录48kg、单位、执行/接收时间和本地规格版本。A为中间批次时不与B一起计暴露。共用机器的 C 要另有交叉污染/清洗证据才能扩大候选，不能从资源关系推定。

正例：重复导入同事件键同负载只计一次。反例：把报废2kg又记为损耗会使50kg投入对应52kg，必须指出不平衡。EPCIS/ISA-95 为事件和资源背景，本地限值与召回决定仍须用户规则和授权。
