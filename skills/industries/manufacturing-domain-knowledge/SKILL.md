# manufacturing-domain-knowledge

## 定位与适用范围

把制造流程和 MES/ERP/QMS 样例整理为有身份、时间、数量及来源的业务知识。用于批次追溯、资源边界和质量证据讨论；不替代过程控制、检验批准或法定召回决定。独立安装即可完成声明的知识任务。

## 输入

最低：业务流程、来源系统/工厂/批次标识和投入产出样例。增强：事件编号、执行时间/观测时间、数量/单位、生产订单、设备、检验方法和本地规格版本。缺失数量标 unknown；缺转换规则不臆造转换。

## 工作流程

1. 读取 [领域记录](references/domain.json)、[来源目录](references/sources.json) 和 [方法](references/method.md)，固定工厂/系统范围及追溯问题。
2. 区分物料定义、物理批次、订单计划和实际执行事件；批次身份使用系统 + 工厂 + 批次号。拆分、合并、返工用新批次和明确事件表达。
3. 将消耗/产出参与关系赋予数量、单位和证据，设备/产线仅作为资源关系，不能据此合并批次或生成血缘。
4. 固定守恒基础和批准的单位换算，区分报废产出、损耗、留存及副产品。缺少质量守恒前提时只交付血缘，不编造平衡规则。
5. 检验记录保留指标、数值/单位、方法/样本范围、执行/接收时间和本地规格版本。EPCIS 或 ISA-95 不决定本地质量阈值。
6. 按双时间筛选已知证据；输出来源路径、重复/冲突处理、数量缺口及上下游候选。召回候选与批准决定分开。

## 输出契约

范围与时间参数；术语/角色表；批次与事件身份；消耗/产出/资源关系表；单位与守恒规则；检验/规格版本映射；来源和分类；未知项、反例和验证结果。属性图建议标 project-curated 或 model-inference，不能标成官方公理。

## 资源与质量检查

[工作示例](examples/worked-example.md) 展示返工、共享设备及已知时间的取舍。核对来源、身份、时间、量纲、重复事件和检验适用范围。来源仅保存索引和原创解释；不打包第三方标准正文或 OPC 节点集。数据库语法按 [交接边界](references/handoff.md) 另行核实。

## 标准依据与缺口

先核实包内来源与知识条目的standard_basis：固定发布机构、版次、具体定位和支持范围，再形成项目解释。standard_gap保留未核实映射、本地政策和补证路径；本地键、阈值或判定公式不因引用标准就成为官方定义。任务缺少适用版本或来源时交付不依赖缺口的部分，并明确待核实项。

交付时读取条目的standard_status：standard-backed仅表示standard_basis.scope内有已核实标准依据，其他本地规则仍按standard_gap保留；nonstandard-modeling明确标为“非标准建模”，标准未取得或精确映射未核实的原因一并列出。不得把背景页、目录或来源分类当成条目符合性。
