# 制造领域的最小方法

原创项目方法；标准来源与版本见 [sources.json](sources.json)，术语见 [domain.json](domain.json)。本地质量规则不能标注为 EPCIS/ISA-95 规定。

身份：批次主键为 source_system + site_id + lot_id；事件为 source_system + event_id。物料定义、订单计划、执行事件、设备和批次各自保留身份。标签相同、物料相同或共用设备不证明相同批次。精确重复事件去重；同事件键不同负载拒绝，待明确更正/取代关系后重做。

血缘：使用 Lot → consumed_by → ProcessEvent → produced → Lot。production 可以无物料输入，consumption 可以无物料输出，但必须声明适用口径；transformation、split、merge、rework 均保留投入、产出及各自新身份。返工不能把输出批次重命名成输入并制造环。共享设备不是血缘路径，若评估交叉污染，必须另外给出清洗/残留/批间转移证据和单独规则。

数量：使用十进制、显式单位和维度；仅在声明的守恒基础上核对。示例 mass 基础要求投入 = 产出 + 已声明损耗；报废若已作为产出，不能再作为损耗重复相加。不存在批准转换就拒绝混合单位，缺数量标 incomplete，不能填零。实际消耗不能用订单计划量代替。已知投入批次的累计消耗不得超过已知期初量与产出量；缺少生产观测时库存完整性仍未证明。此示例全量消耗输入批次，部分消耗须用明确的余料批次或分配记录保留剩余库存。

暴露合计：先建立候选血缘，再按合格状态选择终端批次并按完整身份去重。不能把中间批次与其下游产出一起累计。路径可确定、数量未知时，保留候选且总量 unknown。仅因尚未观察到路径得出的空候选集表示“当前证据未找到”，不保证未发生暴露。

检验：保留指标/数值/单位、方法、样本范围、执行/观测时间以及批准的规格版本。示例指标与0.10mg/kg限值完全虚构。只能在同指标、同量纲、适用版本下判断 pass/fail；样本结果或下游 pass 不能自动撤销上游召回候选。缺规格或无法比较为 unknown。

双时间：event_as_of 约束发生时间，knowledge_cutoff 约束观测时间；晚到事件刷新后再参与血缘。所有输出保留原始事件与路径。召回候选、隔离建议、批准召回和实际回收状态分开，不自动改写生产/质量系统。

EPCIS适配边界：标准7.4.1.2允许错误声明重发原事件，eventID保持相同，除errorDeclaration/recordTime外事件内容不变。先识别并验证这一合法配对，再应用本地同键异文冲突规则；保留原始记录、声明与独立ID的更正事件。错误声明不等于物理库存冲正。包内自定义投影不冒称实现EPCIS捕获/查询接口。
