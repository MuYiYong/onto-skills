# Cybersecurity Ontology Pack

文档组合，无安装器、运行时或隐式依赖。

- [行业技能](../../skills/industries/cybersecurity-domain-knowledge/SKILL.md)：软件供应链概念、标准定位与证据边界。
- [场景技能](../../skills/scenarios/software-vulnerability-impact/SKILL.md)：部署与通告修订、漏洞适用性、完整图规格和反例；已自带基础知识。
- [知识来源](../../knowledge/cybersecurity/README.md)与[完整示例](../../examples/cybersecurity/README.md)：用于维护审查，安装后无需访问仓库。

任一完整Skill可独立安装；组合时显式传递标准版本/范围、身份、来源、缺口和模型。SPDX2.3、CSAF2.0、CVSS4.0提供不同层次的语义；本地图键、修订选择、产品匹配与复核政策保持项目整理。原始标准未打包；合成检查不证明完整标准合规、原生Agent效果或数据库执行。
