# 合成例：可解释候选与反证

input.json中H有带时点和证据的confirmed控制B1与V1，T1为B1→V1的100CNY已执行事件；同源同版本重放只计一次。T2共享电话/仅有股权位置不构成这个控制子规则的充分证据；T3控制关系在交易时点前已结束；T4控制材料在原known_at后才获知；T5仅共同国家持股。原截止只有T1为候选，其余标not_demonstrated，不等于完整法律上的非关联方。

更晚known_at可看到T4，新快照按明确规则输出140CNY，旧快照保留。不同真实交易T6不能按同端点折叠；USD另组呈现。财务合并披露视图可在明确给定范围下移除内部披露金额，但保留候选和原事件；监管视图不能套用这一调整。

ControlAssessment pending/retracted不可当confirmed；控制图循环和多路径必须有限遍历且不双计。完整规则还包括其他人员关系、重大影响、实质判断和2025治理程序，样例不冒称覆盖或给出最终法律结论。
