# 运输异常与交付证据建模示例

[输入](input.json)、[完整模型](graph-model.json)和[具体验收](acceptance.json)均为原创合成数据，并与场景包内副本逐字节同步。

物流模型含9种节点，区分端到端Shipment、运输Consignment、单元、路段、地点/参与方、订舱、单证和证据事件。10Z新预测17Z相对14Z计划晚180分钟；晚到旧预测不覆盖，港区/中转扫描不证明最终配送地点交付。

输入是场景判定所需的有界源投影，不是全量图导入文件。模型给出完整结构和约束，省略的关系实例/来源字段不可补造。验收用例的expected为手算值；对应开发测试只证明这些合成案例及变异反例的离线语义，不证明标准符合性或原生数据库执行。
