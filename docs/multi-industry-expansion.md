# 多行业知识与业务场景扩展

> 本页原生结果按当时25项/13项的冻结源码理解；后续27项源码、条目级标准依据与网络安全场景见[标准优先知识说明](standards-first-knowledge.md)。历史原生结果不覆盖知识改动后的包；原始记录未重写。最终27项的原生发现、GUI和当前代理应用见[兼容报告](compatibility.md)，标准依据与非标准范围见[核验](standards-verification.md)。


本次源码新增12项独立技能，覆盖用户指定的电力、制造、物流、医疗、零售，以及中国监管优先的金融监管报送和关联交易；总库存25项。原13项发布包和日期化原生证据保持原字节，本次扩展随版本 [v26.11.06_Build0721](https://github.com/MuYiYong/onto-skills/releases/tag/v26.11.06_Build0721) 发布。

| 行业/场景 | 知识与重点取舍 | 模型/输入/具体反例 |
| --- | --- | --- |
| 电力停电影响 | IEC CIM/ENTSO-E版本索引；设备/端子/连通性、未知开关、DER、拓扑快照与恢复分段；不将图可达等同实际送电 | [电力示例](../examples/electric-power/README.md) |
| 制造质量追溯 | ISA-95/OPC与GS1事件背景；批次/事件、拆分合并返工、投入产出单位和累计分配；共享设备不产生谱系 | [制造示例](../examples/manufacturing/README.md) |
| 物流异常 | GS1/DCSA版本背景；shipment/consignment/物流单元、计划/估计/实际、消息晚到与交接；不能由计划断言已送达 | [物流示例](../examples/logistics/README.md) |
| 医疗照护事实 | 选定发布版FHIR R4 4.0.1；身份/资源版本、撤销与禁止执行、记录错误/缺失、术语和量纲；不生成诊疗方案 | [医疗示例](../examples/healthcare/README.md) |

每个新行业有中心来源与原创知识、知识技能、独立场景技能、完整中立图模型、真实结构的合成输入、具体expected正反例和组合指南。知识副本、模型/输入/验收副本通过显式开发映射逐字节核对；安装后不依赖仓库或其他Skill。Core和原金融技能作为可选组合，不强制加载。

中国监管优先是用户确认的选项；具体机构、报表制度、模板/指标版本、频率、时限、金额口径和适用程序仍必须由任务正式材料确定。2025关联交易修正已核实，2022原版不能当未修订基线。BCBS/XBRL是国际语义与数据治理背景，不替代中国模板。原准则页面的访问限制和官方来源版本保留在相应包内索引。

实现没有引入安装器、CLI产品、数据/知识服务或规则执行引擎，没有复制外部GQL语法或完整第三方标准。IEC付费正文未访问；FHIR采用明确旧版R4基线；GS1/OPC等只保留索引、原始摘要与映射损失。实际业务输入可选择其他正式版本，不能把检索日期当标准发布日期。

七个场景提供90个具体正反例：电力10、制造14、物流11、医疗17、零售14、报送12、关联交易12。医疗模型明确保留2项待决问题，是完整结构的设计草案，尚不能作为已解决全部映射问题的部署模型。

当前源码已通过资产校验、25项Skill元数据检查和完整回归。新增的[原生证据](../tests/compatibility/multi-industry-native/README.md)记录Codex0.166.0在两种目录布局发现全部25项、读取199个文件，以及12个新增技能在独立项目中的实际CLI使用，全部终态退出0。七个场景的合成任务结果和五个知识技能的概念/边界输出已逐项复核；监管报送包在最终模型改动后完成补跑，旧结果单独保留。金融还完成[独立前向试用与缺口复核](../tests/content-validation/multi-industry-finance/README.md)，修复金额单位、修订引用、版本顺序和运行业务时点问题。

验证按层报告：[测试说明](../tests/README.md)中的离线校验和有界原生调用不证明完整行业标准、监管/临床合规、真实电网/工厂运行或新增数据库执行。原13项CC-Switch GUI/数据库记录保持原范围；新增25项GUI、macOS原生及远程安装升级仍未验证。发布日期前的原生记录按当时源码状态保留，证据内的本地未发布状态是历史上下文；当前发布内容以本页版本链接为准。
