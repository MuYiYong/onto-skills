# 路线图

第一阶段：七项通用本体工程方法，四项金融行业能力，多头借贷与欺诈网络两场景，FIBO 对齐，金融 Pack，独立性和格式验证。

近期验证：在用户实际 CC-Switch 版本上做仓库导入/逐项安装/多项启用/更新/卸载，在 macOS 跑原生检查；收集真实 Agent 的触发与输出质量样例。外部 Graph Type DDL 能力由 nebula-gql-skills 的现有或未来能力确认，不在这里复制实现。

第二阶段：医疗、制造、能源等行业。各自先选择有明确来源和许可的标准，形成知识与场景，再组合复用 Core；不创建空壳行业技能。

第三阶段：补充关联交易等金融场景、标准差异与业务回归材料。related-party-transaction 目前不在交付库存。

长期：覆盖行业理解 → 本体生成 → 属性图 → 外部语法生成 → 图应用语义验收。Claude Code、Kiro 等专门适配属于后续范围，当前不声称已验收。
