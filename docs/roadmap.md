# 路线图

已发布首版：7项Core、4项Finance、多头借贷与欺诈网络2场景，FIBO对齐、金融Pack。原13项的原生兼容/数据库证据保持原版本范围。

上一版扩展：电力、制造、物流、医疗、零售各一项知识和配套场景；金融增加中国监管报送血缘与关联交易。该次范围为25项技能、六个行业；每个新增场景有完整中立模型、合成输入、正反例及来源。参见[扩展记录](multi-industry-expansion.md)。

后续：结合真实脱敏业务材料补充指标/术语版本、量纲转换和更多边界；按用户请求再验具体监管报表、行业Profile和目标数据库。当前项目不提供监管报送、临床诊疗、电网开关或生产执行引擎。

当前27项覆盖七个行业，标准依据与非标准建模逐条区分；最终原生发现/全量CC-Switch GUI及21项当前代理有界任务见[兼容报告](compatibility.md)。平台验证继续区分静态检查、原生发现、代理应用与原13项数据库记录。新行业真实平台/规模/标准符合性需独立证据。外部GQL语法继续复用nebula-gql-skills，不在此复制维护。

发布、其他Agent专门适配及更广行业扩展按明确请求继续；不把已写的通用目录当作未来行业库存。

标准优先知识覆盖与软件供应链场景见[说明](standards-first-knowledge.md)；源码共27项、七个行业，发布内容以Release清单为准。条目需有正式来源定位或明确本地缺口；后续行业按同一规则选择标准、裁剪并提供完整正反例。
