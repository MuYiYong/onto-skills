# Pack 规范

Pack 是 packs/<pack-name>/README.md 的组合说明，没有安装执行逻辑，不声明包管理器式依赖。

说明定位、读者、场景、内部 Skills 及各自职责、推荐顺序、可选外部 Skills、选择性安装与端到端示例。内部链接指向真实可安装目录；未来技能不得列成当前包含。

推荐次序：来源/行业理解 → 概念 → 实体关系 → 标准对齐 → 属性图 → 验证 → 文档/演进；按用户现有材料从适当位置开始。每个 Skill 的基本功能不要求装齐此顺序。

外部 GQL 声明仅记录官方仓库、当前名称与职责、安装/更新办法、验证日期和能力缺口。不固定永久版本，不复制资源，不要求两个项目同步发布。

CC-Switch 无原生 Pack 导入时按 Skill 卡片逐个安装或选择多项；不创建自定义 Pack 安装器。
