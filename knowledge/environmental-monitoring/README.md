# 环境监测知识

选定基线：OGC SensorThings API Part 1: Sensing 1.1（18-088）。条目级依据和缺口见[领域知识](concepts/domain.json)，正式来源、版次、许可见[来源目录](standards/sources.json)。所有摘要均为project-curated；standard-backed仅覆盖每条standard_basis.scope。

本体用于环境观测质量与阈值候选。数据身份、标准字段和业务政策分别记录；标准没有规定的审批、阈值和风险结论保留为非标准建模。完整例子见[场景](../../examples/environmental-monitoring/README.md)。
