# electric-power knowledge

Original MIT summaries are in [concepts/domain.json](concepts/domain.json); third-party source terms and observed versions are in [standards/sources.json](standards/sources.json). Every record has its own classification and source IDs. This is a curated seed, not a copied standard or conformity implementation. Version 1.0.0 introduces the listed IDs; future revisions must record added, changed and retired IDs without reuse.
