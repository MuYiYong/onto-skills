# 教育与学习凭证知识

选定基线：1EdTech Open Badges 3.0 文档1.4.5；W3C VC Data Model 2.0。条目级依据和缺口见[领域知识](concepts/domain.json)，正式来源、版次、许可见[来源目录](standards/sources.json)。所有摘要均为project-curated；standard-backed仅覆盖每条standard_basis.scope。

本体用于学习成就凭证证据核对。数据身份、标准字段和业务政策分别记录；标准没有规定的审批、阈值和风险结论保留为非标准建模。完整例子见[场景](../../examples/education/README.md)。
